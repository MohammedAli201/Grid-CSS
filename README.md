# Responsive Testimonial Grid

A frontend layout exercise based on the Frontend Mentor testimonial grid challenge.

## Explore

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000`.

The implementation uses HTML and CSS Grid. `styles.css` contains layout and responsive styling; `style-guide.md` records the supplied design guidance.

## Scope and attribution

This is a focused CSS learning exercise. The challenge design and supplied assets are not an original product design. See [Frontend Mentor](https://www.frontendmentor.io/).
